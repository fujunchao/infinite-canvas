# 待测试

- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- Docker 镜像发布：GitHub Actions 改为按当前仓库 owner 推送 GHCR 镜像，fork 仓库可生成自己的主应用和文档站镜像；主应用镜像补充 `latest` 标签。
- Docker 部署文档：README、主应用 Compose 和文档站 Compose 改为使用 `ghcr.io/fujunchao/infinite-canvas` 与 `ghcr.io/fujunchao/infinite-canvas-docs` 镜像。
- Docker 镜像构建：`/canvas` 页面增加 Suspense 边界，修复 Next.js 构建时 `useSearchParams()` 导致的预渲染失败。
- 画布节点输入框：资源引用高亮只在输入内容实际包含资源标签时启用，并在中文输入法组合输入时回退原生输入，避免节点下方提示词输入框看不到插入光标。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。

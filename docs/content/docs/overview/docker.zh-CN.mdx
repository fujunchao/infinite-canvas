# Docker 部署

如果你希望在自己的机器或服务器上运行项目，可以直接使用 Docker Compose。

## 使用发布镜像

```bash
git clone git@github.com:fujunchao/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

根目录 Compose 默认使用当前 fork 发布的主应用镜像：

```text
ghcr.io/fujunchao/infinite-canvas:latest
```

启动后访问：

```text
http://localhost:3000
```

## 本地构建镜像

如果需要基于当前源码构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 文档站镜像

文档站位于 `docs/` 目录，按带服务端能力的 Next.js standalone 应用单独构建，不打进主应用镜像。

使用发布镜像：

```bash
cd docs
docker compose up -d
```

文档站 Compose 默认使用：

```text
ghcr.io/fujunchao/infinite-canvas-docs:latest
```

基于当前源码本地构建：

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## 数据说明

当前主应用镜像使用 nginx 托管 Vite 静态产物。画布、我的素材、生成记录和 AI API Key 默认保存在浏览器本地；第三方提示词由浏览器前端直连拉取，不需要额外挂载数据目录。

## 统计分析（可选）

项目默认不接入任何统计。不设置下列环境变量时，页面不会加载统计脚本；设置对应变量即可在自己的部署中启用 GA4、百度统计或同时启用两者。

| 变量 | 说明 |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 衡量 ID（`G-XXXX`） |
| `ANALYTICS_BAIDU_ID` | 百度统计站点 ID（`hm.js?` 后面的 hash） |

```yaml
services:
  app:
    image: ghcr.io/fujunchao/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

或使用 `docker run`：

```bash
docker run -d -p 3000:3000 \
  -e ANALYTICS_GA4_ID=G-XXXXXXXXXX \
  -e ANALYTICS_BAIDU_ID=e8263761cc5c32f5f7a855b8203b965a \
  ghcr.io/fujunchao/infinite-canvas:latest
```

单页应用的路由切换会自动向所有已启用的统计上报 pageview。请只在你自己的站点上配置统计 ID，不要把 ID 提交进仓库。
